# Changelog

This project is under development.

## v1.0

- Added WhatsApp bridge integration with Gemini CLI background execution.
- Added conversational routing modes: `agent`, `trusted_chat`, and `public_chat`.
- Added admin command gate via `ALLOWED_NUMBERS` in `kuun.config`.
- Added contact/group whitelist support for conversational replies.
- Added one-command installer (`install.sh`) and `kuun update` command.
